# 🎯 Valorant Quiz  
An interactive quiz inspired by the world of Valorant, designed to test your knowledge of agents, lore, and abilities — all wrapped in a stylish, immersive interface.

---

## 🚀 About the Project
This project was developed as part of my portfolio, combining:
- HTML  
- CSS  
- A thematic design inspired by Valorant’s HUD  
- Simple and intuitive navigation  
- Fully styled pages for each question  
- Visual feedback for correct and incorrect answers  

The goal is to deliver a fun, fast, and visually consistent experience that matches the style of the game.

---

## 🧩 Quiz Structure

The quiz includes:

### **1. Welcome Page**
- Thematic introduction  
- Start button  
- Valorant logo with glow effect  

### **2. Question Pages**
Each question features:
- Futuristic layout  
- Agent images  
- Styled buttons  
- Hover effects  
- A centered “or” between choices  

Included questions:
- **Kingdom Corporation**  
- **Raze vs Killjoy**  
- **Deadlock vs Cypher**  
- **Astra vs Harbor**

### **3. Wrong Answer Page**
- Visual feedback with `saddeadlock.png`  
- Button to retry  

### **4. Final Page**
- Congratulations message  
- `omen.png` image  
- Button to return to the start
